## 访问流程

```
用户请求流程：

1. 用户在浏览器输入: https://adwall.example.com
   │
   ▼
2. DNS 解析到服务器 IP
   │
   ▼
3. HTTPS 连接到 Nginx (端口 443)
   │
   ├─ 请求 HTML: /index.html
   │  └─ Nginx 从 dist/ 返回
   │
   ├─ 请求 JS: /assets/index-xxx.js
   │  └─ Nginx 缓存 30 天
   │
   ├─ 请求 CSS: /assets/index-xxx.css
   │  └─ Nginx 缓存 30 天
   │
   └─ 请求 API: /api/health
      └─ Nginx 反向代理
         └─ 转发到 :3001
            └─ Express 处理
               └─ 返回 JSON 响应
```

## 文件流动

```
构建阶段：
src/ ──[TypeScript编译]──▶ .js 文件
 │                        │
 ├─ App.tsx              ├─ App.js
 ├─ components/*.tsx      ├─ components/*.js
 └─ utils/*.ts           └─ utils/*.js

构建阶段：
.js + CSS ──[Vite打包]──▶ dist/ (压缩&最小化)
 │                      │
 ├─ 代码               ├─ index.html (47 bytes)
 └─ 样式               ├─ assets/
                        │  ├─ index-CIfVvUo9.css (291 bytes)
                        │  └─ index-CTeAV0gd.js (731 KB gzip=238 KB)
                        └─ (其他静态资源)

部署阶段：
dist/ ──[Nginx服务]──▶ 浏览器
 │
 ├─ index.html ────▶ 首先加载
 ├─ JS ─────────▶ 异步加载 (缓存30天)
 ├─ CSS ────────▶ 异步加载 (缓存30天)
 └─ 图片/字体 ──▶ 按需加载 (缓存30天)

API 调用：
React 应用 ──[/api/*]──▶ Nginx ──[反向代理]──▶ Node.js :3001
   │                                            │
   └─ fetch('/api/health')                    ├─ 处理请求
                                              ├─ 返回 JSON
                                              └─ 回到浏览器
```

## 故障恢复流程

```
如果出现问题:

问题发生
   │
   ├─ 前端 404 错误?
   │  └─ 检查: ls -la /home/wwwroot/miniadwall/dist/
   │  └─ 修复: npm run build && cp -r dist/* /home/wwwroot/miniadwall/dist/
   │
   ├─ API 502 错误?
   │  └─ 检查: pm2 status
   │  └─ 修复: pm2 restart miniadwall-api
   │
   ├─ CORS 错误?
   │  └─ 检查: Nginx 反向代理配置
   │  └─ 修复: 修改 proxy_set_header 配置
   │
   ├─ 文件上传失败?
   │  └─ 检查: chmod -R 777 /home/wwwroot/miniadwall/server/uploads
   │  └─ 修复: 设置正确权限
   │
   └─ 整体出问题?
      └─ 回滚: git reset --hard HEAD
      └─ 重新部署: ./deploy.sh
```

## 更新流程

```
版本更新：

当前版本 v1.0
   │
   ├─ 前端代码更新?
   │  └─ git pull
   │  └─ npm run build
   │  └─ (自动生效，无需重启)
   │
   ├─ 后端代码更新?
   │  └─ git pull
   │  └─ npm install (如果有新依赖)
   │  └─ pm2 restart miniadwall-api
   │
   ├─ 依赖版本更新?
   │  └─ npm update
   │  └─ git commit 保存版本
   │  └─ 重新部署
   │
   └─ 新版本 v1.1 ✓
```
